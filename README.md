# Student-Performance-EDA-Exploratory Data Analysis of student mathematics performance using Python

**Project Overview**

This project performs Exploratory Data Analysis (EDA) on the UCI Student Performance dataset, focusing on students' Mathematics performance.

**Objectives**

1.Analyse student academic performance.

2.Understand grade distributions using histograms and box plots.

3.Explore relationships between study time, absences, and grades.

4.Identify potential outliers.

5.Build an interactive data visualization simulation.

**Technologies Used**


1.Python

2.Google Colab

3.Pandas

4.NumPy

5.Matplotlib

6.Seaborn

7.IPyWidgets

**Dataset**

UCI Student Performance Dataset – Mathematics (student-mat.csv).

Source: https://archive.ics.uci.edu/dataset/320/student+performance

**Visualizations**

1.Grade distribution histogram

2.Grade box plot

3.Scatter plots

4.Correlation heatmap

**Interactive Simulation**

An interactive simulation allows users to select variables and explore different statistical visualizations.

**How to Run**
1.Open the notebook in Google Colab.

2.Upload the Mathematics dataset.

3.Run the notebook cells in sequence.

4.Use the interactive controls to explore the data.

**Outcome**

The project demonstrates the application of exploratory data analysis and interactive visualization techniques to understand student academic performance.
